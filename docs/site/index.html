01 / PLATFORM

One server, controlled access.

Cross-platform

Runtime host detection for Windows and Ubuntu/Linux, native shell discovery, CPU architecture and container capability checks.

Admin controlled

Owner/Admin creates users, enables labs and assigns access. Server-side checks protect Start, Verify, Complete and Reset.

Per-user labs

Separate workspaces, sessions and progress records for each user and lab.

Worldwide transport

Keep the application on the origin PC and publish approved services through Cloudflare Tunnel.

Boot recovery

Windows startup task and Ubuntu systemd service definitions support restart-on-boot operation.

Native terminal

Real PowerShell or Bash execution. Operating-system permissions and UAC/sudo boundaries still apply.

02 / INSTALL

Setup from a clean host.

Clone the repository, then run:

powershell -ExecutionPolicy Bypass -File .\setup.ps1
.\.venv\Scripts\cloud-os.exe setup
.\.venv\Scripts\cloud-os.exe start

For boot recovery, use packaging/install-windows-service.ps1 from an elevated PowerShell session after setup.

bash setup.sh
.venv/bin/cloud-os setup
.venv/bin/cloud-os start

For an always-on server install, use the supplied packaging/cloud-os.service as the systemd service template.

No AWS/Azure account is required by the self-hosted runtime. Curriculum product names remain for syllabus mapping; local equivalents are labelled as such.

Use separate authenticated Cloudflare routes only for services the administrator explicitly approves. Do not expose every host port.

If the physical PC is powered off, the origin is offline. When it boots, OS services can start Cloud OS and cloudflared again automatically. True availability while the PC is off requires another always-on origin.

IMPORTANT

Accurate lab boundaries.

This project does not claim that a self-hosted PC becomes AWS IAM/VPC/EC2/S3, Microsoft Entra ID/Azure, Sentinel, Microsoft's KQL service, or Defender XDR. The curriculum names are preserved, while self-hosted exercises are explicitly identified as local practical equivalents.
